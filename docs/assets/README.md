# Screenshot checklist

This folder is reserved for a **verified, real browser screenshot** of RiftGuard's offline synthetic-data dashboard. No screenshot is bundled with this PR to avoid including a misleading placeholder.

For a screenshot directly generated by the code in this repository, on the case-study branch:

1. Run `python -m riftguard.cli data/version_comparison_events.json --output version-report.json --dashboard version-dashboard.html`.
2. Open `version-dashboard.html` in your browser and select **All versions**.
3. Capture the viewport and inspect it for confidential data.
4. Save it as `docs/assets/riftguard-dashboard-demo.png`.
5. After committing the image, add this link to the case study:

   `![RiftGuard offline reliability dashboard using fictional data](assets/riftguard-dashboard-demo.png)`

Do not use screenshots from real user accounts, private Riot Games systems, or unauthorized telemetry.
